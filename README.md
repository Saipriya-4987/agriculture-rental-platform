# Agriculture Equipment Rental Platform

A full-stack learning project connecting Farmers, Equipment Owners, a
simulated Delivery Partner, and an Admin around agricultural equipment
rental. Built milestone by milestone per the project's TRD v3.

**Docs** - See `docs/` for the full PRD v3 and TRD v3.
**Learning progress** - See `LEARNING-TRACKER.md` for milestone status.

## Structure

- `frontend/` - HTML/CSS/JS at first (M1-M2), then React + TypeScript (from M3)
- `backend/` - Node.js + Express + TypeScript API (built starting M6)
- `docs/` - PRD v3, TRD v3, and other planning documents

## Stack (full detail in TRD v3)

- **Frontend** - HTML, CSS, JavaScript, React, TypeScript, React Router, Tailwind CSS
- **Backend** - Node.js, Express, TypeScript, REST APIs
- **Database** - SQL, PostgreSQL, Prisma
- **Auth** - JWT, bcrypt, RBAC
- **Added after core works** - React Hook Form, Zod, TanStack Query, Supabase Storage, Leaflet + OpenStreetMap
